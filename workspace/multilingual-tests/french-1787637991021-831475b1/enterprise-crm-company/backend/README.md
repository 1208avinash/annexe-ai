# Enterprise CRM Backend

## Features

- FastAPI application with OpenAPI documentation
- JWT authentication
- SQLAlchemy persistence
- Customer CRUD endpoints
- Seeded admin user and sample customers
- Default locale: fr-FR
- Supported locales: en-US, fr-FR, es-ES, de-DE, ar-SA, hi-IN, zh-CN, ja-JP, pt-BR, it-IT

## Default Login

- Email: admin@annexe.ai
- Password: Admin123!

## Run

1. Create a virtual environment.
2. Install dependencies from `requirements.txt`.
3. Start the app with `python -m uvicorn app.main:app`.
