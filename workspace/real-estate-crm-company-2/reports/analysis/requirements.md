# Requirements

## Project

- Name: Real Estate CRM
- Industry: Real Estate
- Business Type: CRM
- Deployment: Docker + PostgreSQL

## Business Requirements

- Support the core needs of a CRM.
- Provide a production-ready workflow for Real Estate.
- Deliver a buildable software foundation that can be extended.

## Functional Requirements

- Authentication
- Dashboard

## Non-Functional Requirements

- Secure by default
- Responsive UI
- FastAPI backend
- JWT-based authentication
- Structured JSON APIs
- Buildable React frontend

## Stakeholders

- Administrators
- Operational Users
- Operations
- Sales
- Management

## Success Criteria

- Customers can sign in securely
- Users can manage customer records
- The dashboard renders successfully
- The application builds without errors
- The backend responds to health and docs requests
