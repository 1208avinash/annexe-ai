# Requirements

## Project

- Name: Operations ERP
- Industry: Operations
- Business Type: ERP
- Deployment: Docker + PostgreSQL

## Business Requirements

- Support the core needs of a ERP.
- Provide a production-ready workflow for Operations.
- Deliver a buildable software foundation that can be extended.

## Functional Requirements

- payments
- Authentication
- Dashboard

## Non-Functional Requirements

- Secure by default
- Responsive UI
- FastAPI backend
- JWT-based authentication
- Structured JSON APIs
- Buildable React frontend

## Stakeholders

- Administrators
- Operational Users
- Operations
- Sales
- Management

## Success Criteria

- Customers can sign in securely
- Users can manage customer records
- The dashboard renders successfully
- The application builds without errors
- The backend responds to health and docs requests
